Gabarits d'export — référence des balises

Un gabarit est un document Word (.docx) ou un classeur Excel (.xlsx) de votre client — page de garde, logo, en-têtes et pieds de page, styles, formules — dans lequel des balises indiquent où Polenta place les données à l'export. Sections 2 à 6 et 8 : Word ; section 7 : Excel.

1. Mise en place

  1. Bibliothèque : panneau Compte › Préférences › Gabarits d'export › Choisir… — un dossier (local, partage réseau ou repo cloné) contenant les gabarits, par exemple un sous-dossier par client. Installer les exemples y copie les gabarits de ce dossier.
  2. Gabarit par défaut d'un projet : page Préférences du projet › Gabarits d'export par défaut. Le choix est enregistré dans .polenta/schema.yaml (chemin relatif à la bibliothèque) et partagé par l'équipe.
  3. À l'export : bouton Exporter › listes Gabarit Word / Gabarit Excel (défaut du projet présélectionné, ou Standard pour le rendu habituel).

2. Syntaxe

BaliseEffet
{{project.label}}Insère une valeur (texte simple).
{{#items}} … {{/items}}Répète le contenu pour chaque élément de la liste. Placées dans une ligne de tableau, les balises répètent la ligne.
{{#isFolder}} … {{/isFolder}}Affiche le contenu si la valeur est vraie / non vide.
{{^isFolder}} … {{/isFolder}}Affiche le contenu si la valeur est fausse / vide.
{{#status == "approved"}} … {{/}}Condition par expression (==, !=, >, &&, ||). {{/}} ferme la dernière section ouverte.
{{@rich.statement}}Insère un champ riche mis en forme (titres, listes, tableaux, images, diagrammes). La balise doit être seule dans son paragraphe (elle le remplace).
{{titre | upper}}Filtres : upper, lower, default:"—", join:", ", date:"dd/MM/yyyy HH:mm" (sur une date ISO, ex. export.iso ou executedAt).
Tapez chaque balise d'un trait, sans changer de mise en forme au milieu : Word peut sinon la découper en morceaux. Une balise mal fermée est signalée à l'export, avec le nom du gabarit et la balise concernée, et aucun fichier n'est produit. Une donnée inconnue donne simplement un texte vide.

Les accolades simples ({texte}) sont laissées telles quelles. Les balises sont aussi reconnues dans les en-têtes et pieds de page.

7. Gabarits Excel

Un gabarit Excel (.xlsx) est un classeur de votre client : logo, cartouche, mise en forme, largeurs de colonnes, formules, mise en forme conditionnelle, graphiques, autres feuilles, mise en page — tout est conservé. Les balises s'écrivent ${…} dans les cellules (et non {{…}}).

BaliseEffet
${project.label}, ${git.commit}, ${count}…Valeur unique (mêmes données qu'en Word, sections 3 à 6). Plusieurs balises et du texte peuvent partager une cellule.
${table:items.id}Ligne modèle : la ligne qui contient ces balises est répétée pour chaque élément de la liste, avec sa mise en forme (bordures, polices, formats, hauteur). Les autres cellules de la ligne (ex. une formule =D6*2) sont recopiées et suivent leur ligne.
${columnNames}Une liste de valeurs, une par cellule vers la droite (en-têtes d'un résultat de requête).
${table:rows.cells}Ligne modèle dont chaque ligne produit ses cellules vers la droite (résultat de requête, colonnes inconnues à l'avance). À placer seule sur sa ligne modèle.

Formules et références : écrivez les formules de synthèse sur la seule ligne modèle — =SOMME(D6:D6), =NB.SI(C6:C6;"Approuvé"), y compris depuis une autre feuille (=NBVAL(Exigences!A6:A6)). Polenta les étend aux lignes générées, comme la mise en forme conditionnelle, les validations de données, le filtre automatique, la zone d'impression, les plages nommées et les séries des graphiques. Excel recalcule tout à l'ouverture.

ListeChamps disponibles
items (exigences, tests)Colonnes visibles de la Vue Excel par nom de champ, section, name, statusLabel, folder (dossier parent), folderPath (chemin « A › B »), level, stepCount, stepsText (procédure « 1. action → résultat attendu »). Une ligne par élément, pas de ligne pour les dossiers. Les champs numériques du modèle sont de vrais nombres.
entries (plan de campagne)id, title, requirementId, testStatus, status, statusLabel, executedAt, executedBy, preconditions, postconditions, stepCount, stepsText ; en-tête ${campaign.id}, ${campaign.title}, ${campaign.component}, ${campaign.baselineRef}…
rows (résultat de requête)cells (toutes les colonnes) ou une colonne par son nom (${table:rows.Statut}) ; ${query.name}, ${columnNames}, ${count}.
rows (analyse d'impact)reqId, direction (Modification / Descendant / Ascendant), depth, id, title, type, status, comment, updatedBy ; ${analysis.label}, ${analysis.from}, ${analysis.to}, ${changes}.
Les champs riches arrivent en texte simple (une cellule n'a pas de mise en forme riche) ; images et diagrammes sont omis. Une valeur commençant par = est écrite comme texte, jamais comme formule.

8. Contenu riche ({{@…}}, Word)

  • Styles du gabarit : titres → styles Titre 1…6 (Heading 1…6), listes → Paragraphe de liste, tableaux → Grille du tableau (Table Grid), citations → Citation (Quote), code → Code HTML. Modifiez ces styles dans le gabarit pour changer le rendu ; un style absent laisse le rendu par défaut.
  • Listes : chaque liste numérotée repart à 1 ; cases à cocher ☐ / ☒.
  • Images : à la taille et au rognage choisis dans l'éditeur, ramenées à la largeur de la page (PNG, JPEG, GIF ; autres formats remplacés par [Image : …]).
  • Diagrammes draw.io : insérés en image, tels qu'affichés dans la Vue Word ; un diagramme introuvable donne [Diagramme : chemin#nœud].
  • Liens internes [[SW-0042]] → SW-0042 ; liens → leur texte.
