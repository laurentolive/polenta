# GH136 — Statuts : afficher le libellé partout (vue tableau et formulaire)

## Symptôme

Un statut défini avec un libellé (`name: valide`, `label: Validé Allo Médic`) apparaît sous son nom
technique (`valide`) dans la vue tableau (cellule, liste déroulante, filtre de colonne) et dans le
formulaire d'édition. La vue document affiche bien le libellé.

## Root cause

La colonne Statut de `ExcelView.tsx` et le champ Statut de `EditView.tsx` sont construits comme un
pseudo-champ `enum` dont `values` sont les **noms** des statuts. `SchemaField` n'avait aucun moyen
de porter un libellé par valeur : les noms servaient donc à la fois de valeur stockée et
d'affichage. `WordView.tsx` et `merge/RenderedObjectPane.tsx` lisent directement `statuses[]` et
affichent `label ?? name`.

## Correctif

- `SchemaField.valueLabels?: Record<string, string>` (`packages/types/src/schema.ts`) : libellé
  affiché par valeur d'enum, la valeur reste stockée. Posé uniquement par le renderer sur le
  pseudo-champ statut, jamais écrit dans `schema.yaml`. Helper `statusValueLabels(statuses)`.
- `EditView.tsx` : le pseudo-champ statut porte `valueLabels` ; la liste déroulante d'un `enum`
  affiche le libellé (nom technique en info-bulle de l'option).
- `ExcelView.tsx` :
  - le pseudo-champ statut porte `valueLabels` (mémo déplacé avant `getCellText`, qui en dépend) ;
  - cellule : libellé affiché, info-bulle « libellé (nom) — double-cliquer pour éditer » ;
  - liste déroulante d'édition : libellés ;
  - `getCellDisplayText` (libellé à la place du nom pour la colonne statut) sert à la largeur auto
    et au filtre de colonne ; `getCellText` reste la valeur éditée.

Un statut sans `label` s'affiche sous son nom, comme avant. Le filtre texte global (barre du panneau)
cherche toujours dans les valeurs brutes, donc par nom technique.

## Vérifier

1. Modèle de données : un type d'exigence avec un statut `name: valide`, `label: Validé Allo Médic`.
2. Vue tableau de ce type : la cellule Statut affiche « Validé Allo Médic » (info-bulle avec
   `valide`), la liste déroulante au double-clic propose les libellés, le filtre de la colonne Statut
   retient la ligne avec « Validé ».
3. Formulaire d'édition : le champ Statut affiche « Validé Allo Médic ».
4. Changer le statut par la liste : le YAML porte toujours le nom technique (`status: valide`).
