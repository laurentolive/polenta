# GH139 — Champs visibles : « Réinitialiser » revient au défaut de l'équipe, porté par le schéma

> Bug (milestone D, prérequis de #203). Correctif décidé avec l'humain le 2026-10-29 : le défaut
> d'équipe des colonnes visibles passe dans le **schéma** (`defaultVisible`), et « Réinitialiser »
> retire le choix personnel.

## Root cause

« Réinitialiser » (`FieldConfigModal`) écrivait dans le `.pref` personnel un défaut **codé en dur**
(section / nom / ID / statut + 3 premiers champs, sans `version`), au lieu de retirer le choix
personnel. Comme `pref:get-field-visibility` renvoie le choix personnel dès qu'il existe, le défaut
d'équipe (`polenta-config` `defaults.preferences.fieldVisibility`, GH45) n'était plus jamais
appliqué à un type déjà réglé une fois.

## Correctif

| Point | Changement |
|---|---|
| Modèle | `defaultVisible?: boolean` sur `SchemaField` et sur `LinkTypeDefinition` (écrit seulement si vrai) |
| Défaut d'une vue | `defaultVisibleFields(typeDef, { linkTypes, objectTypeRef, view })` : système (section, nom, ID, statut, `version` / `steps`), champs `defaultVisible` dans l'ordre du schéma (aucun : les 3 premiers), colonnes des types de lien `defaultVisible` qui concernent le type (`link-out::` / `link-in::` en vue Tableau si source et cible, `link::` sinon) |
| Réinitialiser | Vue Système : retire `excel` / `word` et `showFolders*` du `.pref` (écriture partielle `null`, GH176) ; la vue retombe sur le défaut du schéma. Défaut interne du panneau aligné sur `defaultVisibleFields` |
| polenta-config | `fieldVisibility` n'est plus lu ; avertissement « n'est plus lu — déclarer `defaultVisible: true`… » dans le panneau Compte ; `pref:get-field-visibility` ne renvoie que le choix personnel |
| Éditeur de schéma | colonne « Vis. » dans le tableau des champs, case « Colonne affichée par défaut » sur chaque type de lien (et conservée à l'enregistrement de la page Liens, qui perdait les clés inconnues) |
| MCP | `defaultVisible` accepté par `add_field` et `add_link_type` |

Point secondaire de l'issue (cache `forge-config.json` non réécrit) : sans objet pour les champs
visibles désormais ; non traité.

## Comment vérifier

1. Éditeur de schéma : cocher « Vis. » sur deux champs d'un type d'exigence et « Colonne affichée par
   défaut » sur un type de lien qui le concerne ; enregistrer.
2. Vue Tableau de ce type, sans choix personnel : section / nom / ID / statut / version, les deux
   champs, la (les) colonne(s) du lien.
3. ⚙️ : décocher / cocher des colonnes, puis « Réinitialiser » : retour exact au point 2 ; le `.pref`
   ne contient plus `excel` pour ce type.
4. Vue Document : même chose, colonne `link::<type>` unique.
5. Une `polenta-config` avec `fieldVisibility` : avertissement dans le panneau Compte, aucun effet.

Tests : `renderer/lib/defaultVisibleFields.gh139.test.ts`, `pref-defaults.test.ts`,
`forge/team-config.test.ts`, e2e `gh139-default-visible.spec.ts`.
