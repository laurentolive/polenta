# GH169 — Vue Excel : IDs d'une colonne de lien cliquables

Issue : #169 (type:bug)

## Constat

Vue Word : dans la section des liens d'un élément, chaque ID lié est cliquable et ouvre l'objet
lié (Ctrl/Cmd+clic : nouvel onglet). Vue Excel : dans une colonne `link::<type>`, les IDs liés
sont du texte brut — pour naviguer, il faut éditer la cellule (double-clic → popover des liens)
puis cliquer l'ID dans le popover.

## Root cause

`LinkCell` (`apps/desktop/src/renderer/components/system/ExcelView.tsx`) affichait la valeur
texte de la cellule (`getLinkCellValue` : `A, B | C, D`) d'un seul bloc, sans geste par ID.
La navigation (`onNavigateToObject`) n'était branchée que sur le popover d'édition des liens.

## Correctif

- `ExcelCellActions.navigateToObject` : nouvelle action stable de cellule (délègue à
  `onNavigateToObject`, comme les autres actions via la ref T176) — la cellule mémoïsée continue
  de ne recevoir que des props primitives.
- `LinkCell` découpe sa valeur (` | ` entre sortants et entrants, `, ` entre IDs) et rend chaque ID
  dans un `<span>` souligné au survol, avec le même libellé que la vue Word
  (`system.shared.clickToNavigate`). Clic → navigation ; Ctrl/Cmd+clic → nouvel onglet ;
  `stopPropagation` pour ne pas sélectionner/ouvrir le popover.
- L'ID porte `data-cell-dblclick-ignore` : un double-clic sur un ID n'ouvre pas l'éditeur
  (`excelCellStore.ts`). Le clic ailleurs dans la cellule garde son geste (sélection ;
  double-clic / F2 = édition des liens).

## Popover d'édition des liens qui ne se refermait pas (signalé en test)

Root cause : (1) aucune gestion d'Échap pour ce popover ; (2) **chaque** cellule de lien portait
`data-link-popover`, marqueur que le gestionnaire « clic à l'extérieur » considère comme
« dans le popover » — un clic sur n'importe quelle cellule de lien le laissait ouvert.

Correctif : la cellule porte `data-link-cell` (repère) et `data-link-popover` **seulement quand
elle est ouverte** (son propre clic garde le geste de bascule) ; un écouteur `keydown` Échap,
posé avec l'écouteur `mousedown` tant que le popover est ouvert, le referme.

## Vérification

- Automatique : `e2e-web/gh169-excel-link-navigate.spec.ts` — clic sur un ID d'une cellule de lien
  en vue tableau → l'éditeur de l'objet lié s'ouvre, sans popover d'édition (GH169-1) ; popover
  refermé par Échap, par un clic hors cellule et par un clic sur une autre cellule de lien
  (GH169-2 — échoue sans le correctif, vérifié).
- Manuelle : vue Exigences → Vue tableau, afficher une colonne de lien ; cliquer un ID → l'objet
  lié s'ouvre ; Ctrl+clic → nouvel onglet ; double-clic sur une zone vide de la cellule → popover
  d'édition des liens comme avant.
