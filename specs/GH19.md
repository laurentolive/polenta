# GH19 — Modèle de données : alignement des composants repo / locaux et de leurs éléments

## Root cause

Dans `StructureTab.tsx`, chaque type de ligne calculait son retrait avec sa propre formule :

| Ligne (enfant d'un repo de niveau d) | Avant : x du chevron / de l'icône |
|---|---|
| Dépendance repo (`RepoRow`, depth d+1)  | `24 + 16d` |
| Composant local (`LocalNodeRow`)        | `32 + 16d` (pas de `px-2`, retrait absolu `32 + indent`) |
| Élément sous le repo                    | icône à `40 + 16d` (32px sous le chevron du repo) |
| Élément sous un composant local         | icône à 8px seulement sous le chevron du composant |
| Dépendance sous un composant local      | `depth = round(indent/16)` → 8px plus à gauche que les composants locaux frères |

Les composants repo et locaux d'un même parent n'étaient donc pas alignés, et les éléments
(documents) n'avaient pas le même retrait selon leur parent.

## Correctif

Une seule échelle pour tout l'arbre : une ligne de niveau `depth` (repo, composant local ou
élément) commence à `rowPadding(depth) = 8 + 16·depth` px, et ses enfants sont au niveau `depth + 1`.
- `LocalNodeRow` prend un `depth` (au lieu d'un `indent` absolu), avec le même `px-2 py-1.5` que `RepoRow`.
- Les dépendances imbriquées sous un composant local sont au niveau `depth + 1`, comme ses composants locaux.
- `ElementLeaf` réserve la place du chevron (14px) : l'icône d'un élément est dans la même colonne
  que l'icône de dossier de ses composants frères.
- Les messages « Chargement… » / « Aucun élément » sont alignés sur les icônes du niveau enfant.

## Comment vérifier

Projet → Modèle de données → onglet Structure, sur un repo qui contient à la fois des éléments
propres, des composants locaux (dont un imbriqué), et des dépendances repo (dont une rattachée à un
composant local) :
- les chevrons des composants repo et locaux enfants d'un même parent sont sur la même verticale ;
- les icônes des éléments sont alignées sur les icônes de dossier des composants frères, que le
  parent soit un repo ou un composant local ;
- les lignes de composants locaux et de repos ont la même hauteur ;
- le drag & drop (réordonnancement / reparentage) fonctionne toujours.
