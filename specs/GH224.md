# GH224 — Vue Tableau : filtre d'affichage sur la colonne « Couverture »

Issue : #224 · Milestone C — Fonctionnalités client · type:feature

## Description fonctionnelle

Dans la vue Tableau (Vue Excel), toutes les colonnes portent l'icône de filtre de colonne
(T51) sauf `Étapes` et `Couverture (sys)` (`coverageStatus`, T138). La colonne Couverture
devient filtrable avec **le même mécanisme que les autres colonnes** : icône dans l'en-tête,
popover avec champ texte et options casse / mot entier / regex.

Le texte filtré est le **libellé affiché** par le badge de couverture, dans la langue de
l'interface : `Non couvert`, `Couvert`, `Validé`, `En échec`, `À revalider` (en :
`Not covered`, `Covered`, …). C'est la même règle que pour la colonne Statut, filtrée sur son
libellé et non sur sa valeur technique.

## Comportements attendus

| Cas | Comportement |
|-----|--------------|
| Colonne Couverture visible | icône de filtre dans l'en-tête, comme les autres colonnes |
| Saisie `valid` | seules les exigences au statut « Validé » restent |
| Saisie `non` | seules les exigences « Non couvert » restent |
| Saisie `couvert` (contient, sans regex) | « Couvert » **et** « Non couvert » restent — recherche « contient » identique aux autres colonnes |
| Regex `^couvert` | seules les exigences « Couvert » restent |
| Ligne sans badge (objet sans entrée de couverture, ex. type test) | texte vide : exclue dès qu'un filtre non vide est saisi |
| Combinaison | ET avec les autres filtres de colonnes et avec le filtre global (inchangé) |
| Masquage de la colonne, changement de composant/type | filtre oublié, comme les autres colonnes (inchangé) |

La couverture affichée n'est pas recalculée : le filtre lit la même donnée que le badge
(`coverageByReqId`, issue de `api.traceability.matrix`).

## Indicateur

Pas de nouvel indicateur : `coverageStatus` existe déjà et sert une fonction de Polenta
(couverture test ↔ exigence, `SPEC-TECH-stack.md` §1.1). Le ticket ajoute seulement un filtre
d'affichage dessus.

## Critères d'acceptation

1. L'en-tête `Couverture (sys)` de la vue Tableau affiche l'icône de filtre ; elle passe en
   couleur active quand un filtre est saisi.
2. Avec le filtre `valid`, seules les lignes dont le badge affiche « Validé » sont visibles
   (dossiers toujours affichés).
3. Avec la regex `^couvert`, les lignes « Non couvert » sont masquées et les lignes « Couvert »
   restent.
4. `Échap` vide le filtre et ferme le popover, comme pour les autres colonnes.
5. La colonne `Étapes` reste non filtrable.

## Hors scope

- Filtre par liste de cases à cocher (valeurs énumérées) — même mécanisme texte que les autres
  colonnes ; à ouvrir dans un ticket séparé si besoin, pour toutes les colonnes enum.
- Vue Document (filtre global seul, inchangé) et filtre global : le libellé de couverture
  n'entre pas dans le périmètre du filtre global.
- Persistance des filtres de colonne (toujours non persistés).
