# GH227 — Bug : le champ description d'une campagne est invalide

## Symptôme

Sur la page d'une campagne, le champ richtext « Description » (type de campagne) :
- n'affiche pas la nouvelle valeur après « Modifier les champs » → « Enregistrer » ;
- garde la description de la campagne précédente quand on passe à une autre campagne.

## Root cause

`RichTextViewer` crée son éditeur TipTap avec `useEditor({ content: value })` : `content` n'est
lu qu'à la création de l'éditeur, les changements ultérieurs de la prop `value` étaient ignorés.

- **Enregistrement** : à la fermeture du panneau d'édition, le viewer est remonté sur la campagne
  encore en cache (ancienne valeur) ; le refetch déclenché par l'invalidation arrive ensuite et ne
  met plus le viewer à jour.
- **Changement de campagne** : la page est réutilisée (même route, seul `campaignId` change) ; si
  la campagne cible est déjà en cache, pas d'état de chargement, donc pas de remontage — le viewer
  garde le contenu de la campagne précédente.

Le même composant sert aux pages d'exécution / relecture d'un test (préconditions, actions,
résultats attendus, notes) : elles bénéficient du même correctif lors du passage d'une entrée à
l'autre.

## Correctif

`apps/desktop/src/renderer/components/RichTextViewer.tsx` : effet de resynchronisation sur
`value` (même idiome que `RichTextField`) — `setContent` quand la valeur reçue change et diffère
du markdown affiché ; rien au montage (pas de re-parse inutile).

## Comment vérifier

Automatique : `e2e-web/gh227-campaign-description.spec.ts` (échoue sans le correctif) —
A → B → retour sur A (en cache) affiche chaque fois la bonne description ; modification de la
description de A via « Modifier les champs » puis « Enregistrer » affichée sans rechargement.

Manuel (projet démo lave-linge, vue Campagnes) :
1. Ouvrir une campagne avec une description, puis une autre, puis revenir sur la première par la
   liste : la description suit la campagne affichée.
2. Modifier la description (crayon), enregistrer : la nouvelle description s'affiche aussitôt.
