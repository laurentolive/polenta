# GH233 — Résolution de conflits : le panneau latéral affiche « Projet »

Issue : #233 · Type : bug · Corrigé dans la branche de #222 (retour de validation du 2026-10-29).

## Constat

À l'ouverture de l'éditeur de résolution (`/merge-resolve`), le panneau latéral de l'application
affichait le panneau « Projet » ; la liste « Fichiers en conflit » était dans la page, à côté.

## Root cause

`AppLayout.deducePanel` ne connaissait pas la route `/merge-resolve` et retombait sur `project`.

## Correctif

- Nouveau panneau latéral « Fichiers en conflit » (`components/sidebar/MergeFilesPanel.tsx`),
  choisi pour `/merge-resolve` (`Panel` `merge`, sans icône dans la barre d'activité) : fichiers de
  la session, état, conflits restants, avancement.
- Le fichier ouvert passe dans l'URL (`file`), partagé par le panneau et l'éditeur
  (`MergeResolvePage` ne porte plus la liste).

## Comment vérifier

- e2e `gh222-raw.spec.ts` (H11) : le panneau latéral est « Fichiers en conflit », pas « Projet ».
- À la main : provoquer un conflit, « Résoudre les conflits » → le panneau latéral liste les
  fichiers en conflit ; un clic ouvre le fichier ; « Merger » passe au suivant.
