# GH235 — Bug : changer la visibilité d'une colonne réinitialise l'ordre des colonnes

## Symptôme

Vue Système, vue tableau (et sélecteur de tests d'une campagne, même panneau ⚙️) : après avoir
réordonné les colonnes par glisser-déposer, cocher ou décocher une colonne dans « Champs
visibles » remet **toutes** les colonnes dans l'ordre par défaut.

## Root cause

`FieldConfigModal.toggle` reconstruisait la liste des colonnes visibles en la filtrant sur
l'ordre canonique du panneau (champs système, custom, colonnes calculées, étapes, liens) pour
replacer la colonne recochée « à sa place » — ce qui retriait aussi toutes les autres colonnes et
écrasait l'ordre choisi par l'utilisateur.

## Correctif

`components/system/fieldToggle.ts` — `toggleVisibleField(current, field, canonicalOrder)` :
- décocher retire la colonne, les autres gardent leur ordre ;
- cocher insère la colonne juste après la plus proche colonne affichée qui la précède dans l'ordre
  canonique (en tête s'il n'y en a pas), sans déplacer les autres ; une colonne hors de l'ordre
  canonique va en fin de liste.

Sans réorganisation par l'utilisateur, le résultat est identique à l'ancien comportement.
`FieldConfigModal` utilise cette fonction pour tous ses onglets (Tableau, Document, sélecteur).

## Comment vérifier

Automatique :
- `fieldToggle.gh235.test.ts` (unitaire) ;
- `e2e-web/gh235-column-order.spec.ts` (échoue sans le correctif) — ordre `ID, Statut, Label`
  posé dans la préférence ; cocher Version → `ID, Statut, Version, Label` ; décocher Statut →
  `ID, Version, Label`.

Manuel : Vue Système d'un type, vue tableau ; déplacer une colonne par glisser-déposer ; ouvrir
l’œil (« Configurer les colonnes »), cocher puis décocher une autre colonne : l'ordre réorganisé est conservé.

## Ajout demandé en validation — icône du bouton

Le bouton qui ouvre le panneau « Champs visibles » (barre d'outils de la Vue Système et
sélecteur de tests d'une campagne) porte une icône **œil** (`Eye`, lucide) au lieu de la roue
crantée (`Settings`) : il règle la visibilité des colonnes, pas des paramètres. Infobulle
inchangée (« Configurer les colonnes »). Mises à jour SPEC : `SPEC-SYSTEM-VIEW.md` §Toolbar de la
vue document et §Configuration des champs (icône + règle d'ordre des colonnes).
