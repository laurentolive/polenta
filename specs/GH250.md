# GH250 — Vue Excel : les info-bulles des cellules recouvrent la popup de lien

## Root cause

Plusieurs éléments de la grille portaient un attribut `title`. Le navigateur affiche cette
info-bulle native au survol, sans que le code puisse la positionner ni la masquer ; elle recouvrait
la popup d'aperçu d'un ID (`ElementLink`), et la popup d'édition d'un lien.

Un premier correctif n'avait retiré que le `title` de `LinkCell` : les cellules de champ, dont le
contenu peut aussi porter des liens (GH229), et le lien lui-même gardaient le leur. La bulle restait
donc visible sur un vrai projet, alors que le test, limité à `LinkCell`, passait.

## Correctif

Retirées :

| Info-bulle | Emplacement |
|---|---|
| ID Polenta d'un lien dont l'ID affiché diffère (partout, pas seulement en vue Excel) | `ElementLink` |
| « Double-cliquer ou F2 pour modifier », avec la valeur technique d'une énumération | cellules de champ, richtext, nom d'objet et de dossier |
| Liste des IDs de la cellule | `LinkCell` |
| Nombre d'étapes, déjà affiché dans la cellule | `StepsCell` |

Le contexte `ExcelCellLabels`, sans usage restant, et ses quatre clés de traduction disparaissent.

Conservées, sur décision de l'humain :
- colonnes calculées (GH70) : le texte vient des scripts du projet et n'est visible nulle part ailleurs ;
- boutons d'icône et ⚠ d'erreur de calcul : sans texte, ils ne sont plus compréhensibles ;
- URL d'un champ lien : seul moyen de voir la cible avant de cliquer quand le libellé diffère.

Pertes assumées :
- l'ID Polenta d'un lien à ID affiché se lit dans la popup d'aperçu ;
- la valeur technique d'une énumération ne se lit plus au survol ;
- le contenu complet d'une cellule de lien tronquée ne se lit plus au survol.

## Comment vérifier

Vue tableau, toutes colonnes affichées, sur un projet réel (de préférence avec `displayIdField`) :
- survoler les cellules : plus d'info-bulle, sauf colonnes calculées et URL d'un champ lien ;
- survoler un ID : la popup d'aperçu reste entièrement lisible et donne l'ID Polenta.

Tests automatiques : `e2e-web/gh250-cell-tooltips.spec.ts` (échoue sans le correctif),
`gh229-element-refs` (N7 : lien à ID affiché sans `title`), `gh70-computed-column` (info-bulle
conservée).
