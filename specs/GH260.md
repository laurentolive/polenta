# GH260 — Lancer l'appli sous Windows salit le dossier git

## Root cause

Sous Windows, `core.autocrlf=true` sort `routeTree.gen.ts` en CRLF alors que le générateur TanStack
l'écrit en LF. Le générateur le voit différent et le réécrit à chaque lancement, et git le signale
alors comme modifié, sans différence de contenu. Ses fichiers temporaires, dans
`apps/desktop/.tanstack/tmp/`, n'étaient pas ignorés ; l'un d'eux avait été commité par erreur.

## Correctif

- `.gitattributes` : `apps/desktop/src/renderer/routeTree.gen.ts text eol=lf`.
- `.gitignore` : `apps/desktop/.tanstack/`, et retrait du fichier temporaire commité.

## Comment vérifier

Sous Windows, depuis un checkout propre, lancer `pnpm build:web` dans `apps/desktop` :
`git status --porcelain` reste vide.

## Copies de travail existantes

Une copie déjà en CRLF (dossier principal, autres worktrees) doit ressortir le fichier une fois après
avoir reçu ce correctif, sinon il peut rester affiché comme modifié sans différence de contenu :

```
rm apps/desktop/src/renderer/routeTree.gen.ts
git checkout -- apps/desktop/src/renderer/routeTree.gen.ts
```
