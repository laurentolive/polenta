# GH345 — e2e-desktop gh202, gh204 et gh238 en échec dès leur mise en place

## Root cause

GH289 a changé la cible du bouton « Version » de la barre d'activité : le panneau Version s'ouvre
désormais sur « Version produit » (`/versions`, GH201), plus sur l'arbre de versions (`/graph`).

1. **Tests** — la mise en place des trois specs cliquait sur « Version » puis attendait
   `/graph` : expiration au bout de 30 s, et 0 test exécuté.
2. **Bug produit révélé par gh238** — `isVersionRoute` (`components/terminal/terminalShortcut.ts`),
   qui décide où le terminal Git Bash s'affiche et où `Ctrl+ù` agit, ne listait que `/graph`,
   `/diff`, `/version-diff` et `/baseline`. Sur « Version produit » (l'accueil du panneau Version),
   ainsi que sur `/local-impact` et `/revalidation` (rattachées au panneau par GH243), le bouton
   « Terminal (Ctrl+ù) » de l'en-tête était affiché mais sans effet, et `Ctrl+ù` aussi.

## Correctif

- `isVersionRoute` reprend toutes les routes du panneau Version de `deducePanel` : les quatre
  d'origine, `/local-impact`, `/revalidation` et « Version produit » (`/versions`,
  `/versions/backlog`, `/version/<id>`). La règle de `isProductVersionsPath` est recopiée, pour
  garder le module sans React.
- gh202, gh204 : la mise en place attend `/versions`.
- gh238 : la mise en place attend `/versions`, puis ouvre « Voir l'arbre de versions » (`/graph`) :
  E2 vérifie la section « Stagés », qui est dans la barre latérale de l'arbre.
- Nouveau test e2e GH345 dans gh238 : terminal ouvert, passage sur « Version produit » → toujours
  affiché, `Ctrl+ù` le masque puis le réaffiche (rouge sans le correctif, vert avec) ; test
  unitaire `isVersionRoute` étendu.
- `SPEC-ELECTRON-DESKTOP.md` (terminal, §19.8b) : liste des routes mise à jour.

## Vérifications

- `pnpm typecheck` OK ; `pnpm test` OK (desktop 1774/1774).
- e2e desktop : gh202 1/1, gh204 1/1, gh238 8/8, gh210 1/1, gh237 4/4.
- Rouge sans le correctif : gh238 « GH345 » échoue (`toBeVisible`), puis E7 par contrecoup.

## Comment vérifier à la main

1. Ouvrir un projet, cliquer sur « Version » dans la barre d'activité (« Version produit »).
2. `Ctrl+ù` → le terminal Git Bash s'ouvre ; le bouton « Terminal » de l'en-tête le masque et le
   réaffiche.
3. Passer sur l'arbre de versions, puis revenir sur « Version produit » → le terminal reste ouvert,
   avec le même contenu.
