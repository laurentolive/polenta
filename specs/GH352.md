# GH352 — Popup fermée quand une sélection de texte commencée dedans se termine sur le fond

Issue : #352 — type bug.

## Constat

Modèle de données, ajout d'un type : sélectionner le contenu du champ *nom* en maintenant le
clic, puis relâcher le bouton en dehors de la popup → la popup se ferme.

## Root cause

Les popups ferment par `onClick` sur leur fond (`<div className="fixed inset-0 …" onClick={onClose}>`),
le contenu arrêtant la propagation de ses propres clics. Quand l'appui a lieu dans la popup et le
relâchement sur le fond, le navigateur envoie le `click` à l'**ancêtre commun** des deux cibles —
le fond lui-même — dont le gestionnaire ferme. Le défaut n'est pas propre au modèle de données :
toutes les popups construites sur ce modèle (53 fonds dans 45 fichiers du renderer) l'avaient.

## Correctif

- `apps/desktop/src/renderer/lib/backdropDismiss.ts` : `backdropDismiss(onDismiss, { stopPropagation? })`
  renvoie `onMouseDown` / `onMouseUp` / `onClick` à étaler sur le fond. Il mémorise sur l'élément
  du fond la cible de l'appui et celle du relâchement, et ne ferme que si les deux sont la cible du
  clic. Un clic sans appui mémorisé (clavier, clic synthétique) ferme comme avant. Sans hook : il
  s'utilise aussi dans du JSX conditionnel.
- Tous les fonds `inset-0` dotés d'un `onClick` passent par lui (`{...backdropDismiss(onClose)}`),
  y compris les fonds transparents des menus (sans effet visible pour eux, mais règle uniforme).
  Seul `CheckoutConfirmModal` garde `onClick={e => e.stopPropagation()}` : son fond ne ferme pas.
- Garde-fou : un test unitaire parcourt les `.tsx` du renderer et échoue si un `<div … inset-0 …>`
  porte un autre `onClick` — une nouvelle popup ne peut pas réintroduire le défaut.

## Tests

- `src/renderer/lib/backdropDismiss.gh352.test.ts` : comportement du helper (clic franc, glissé
  popup → fond, glissé fond → popup, clic clavier, fermeture désactivée, propagation) et garde-fou
  ci-dessus (vérifié : il signale un fond remis en `onClick` brut).
- `e2e-web/gh352-backdrop-drag.spec.ts` : dans la popup d'un type du modèle de données, sélection
  dans le champ nom relâchée au coin de la fenêtre → popup ouverte, texte sélectionné ; appui sur le
  fond relâché dans la popup → ouverte ; clic franc sur le fond → fermée. **Rouge sans le correctif**
  (vérifié en revenant à `onClick={requestClose}`), vert avec.

## Comment vérifier

1. Modèle de données → ajouter un élément (ou ouvrir un type existant).
2. Dans le champ nom, appuyer à droite du texte, glisser vers la gauche puis hors de la popup,
   relâcher : la popup reste ouverte, le texte sélectionné.
3. Cliquer franchement sur le fond grisé : la popup se ferme.
4. Même geste sur une autre popup au choix (paramètre, nouvelle version, confirmation de suppression…).
