# GH355 — Composant ajouté avec label vide : affiché « Produit » au lieu de son nom

## Constat

Structure → « + Composant » (repo séparé, case « Composant local » décochée). Le champ
**Label affiché** montre le nom du composant en grisé : c'est un *placeholder*, le champ est vide.
Laissé tel quel, le composant apparaît après l'ajout avec le label **« Produit »**.

## Root cause

`StructureTab.handleSubmitDependency` (T177) n'écrit le label sur le node `root` du schéma de la
dépendance que s'il est saisi — volontairement, pour ne pas écraser le label d'un repo existant.

Pour un repo **neuf** (créé sur le serveur, sans `.polenta/schema.yaml`), `schema.get` renvoie
`DEFAULT_SCHEMA` (`schema.service.ts`), dont le node `root` porte `label: Produit` — libellé
voulu pour la racine d'un *projet* neuf. L'amorçage des types par défaut (cases Exigences /
Tests / Campagnes, cochées par défaut) enregistre ce schéma tel quel : le composant hérite de
« Produit ».

## Correctif

Même fonction : quand le label est laissé vide **et** que le repo n'a pas de label propre
(le nœud de l'arbre du workspace, lu sur le `schema.yaml` brut, n'en porte aucun), le nom du
composant est écrit comme label — ce qu'annonçait le placeholder.

- Repo existant avec son propre label : inchangé (pas écrasé).
- `DEFAULT_SCHEMA` inchangé : la racine d'un projet neuf reste « Produit ».
- Rien n'est écrit en plus si aucun type n'est amorcé et qu'aucun label / description n'est saisi
  (un repo existant monté sans amorçage n'est pas touché).

Autres chemins recensés : l'édition d'une dépendance part du label existant ; le déplacement
(`workspaceActions.ts`) ne touche pas au schéma ; le composant local utilisait déjà
`label || name`. Seul l'ajout d'une dépendance en repo séparé était concerné.

Les composants déjà ajoutés avec « Produit » ne sont pas migrés : renommer via « Modifier le
composant ».

## Comment vérifier

- e2e : `e2e-web/gh107-create.spec.ts` C-13 (composant créé sur le serveur depuis Structure, label
  vide) vérifie maintenant que le `schema.yaml` du composant porte son nom et pas « Produit ».
- Manuel : Structure → « + Composant » → nom `comp-test`, label vide, « Créer le repo sur le
  serveur » → Ajouter. Le composant s'affiche `comp-test` ; son `.polenta/schema.yaml` a
  `label: comp-test` sur `root`. Avec un label saisi, c'est ce label qui est affiché.
