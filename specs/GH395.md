# GH395 — `pnpm lint` ne vérifie rien

Issue : #395 (type:bug). Décision humaine (2026-11-18) : configurer ESLint (TypeScript + react-hooks
au minimum) et brancher `pnpm lint` ; le lint reste au niveau 1 de `WORKFLOW.md`.

## Root cause

- `package.json` racine : `"lint": "turbo lint"`, mais **aucun paquet** n'avait de script `lint` :
  turbo ne trouvait aucune tâche et sortait en succès sans rien exécuter.
- `eslint`, `typescript-eslint`, `eslint-plugin-react-hooks` et `globals` étaient déjà en
  devDependencies racine (plages `^9`, `^8`, `^5`, `^15`), mais **aucun fichier de configuration**
  (`eslint.config.*`) n'existait : même lancé à la main, ESLint n'aurait rien su vérifier.
- Le code contenait pourtant des `eslint-disable-*` (supposant un lint actif), dont plusieurs ne
  correspondaient plus à aucune erreur.

## Correctif

### Configuration retenue

- `eslint.config.mjs` (flat config) à la racine, **un seul passage ESLint sur tout le monorepo** :
  `"lint": "eslint . --max-warnings=0"` dans le `package.json` racine (la tâche `lint` de
  `turbo.json`, qui ne servait à rien, est retirée). La commande reste `pnpm lint` : `WORKFLOW.md`
  est inchangé.
- Versions exactes : `eslint` 9.39.5, `@eslint/js` 9.39.5, `typescript-eslint` 8.72.1,
  `eslint-plugin-react-hooks` 7.1.1, `globals` 17.13.0 (TypeScript du repo : 5.9.3).
  ESLint 10 écarté pour l'instant : il exige Node ≥ 20.19, alors que `.nvmrc` et `engines` disent
  seulement 20 / ≥ 20.0.
- Règles : `@eslint/js` recommended + `typescript-eslint` recommended, **sans type-checking**
  (environ 40 s pour ~1 170 fichiers). `react-hooks/rules-of-hooks` et
  `react-hooks/exhaustive-deps` en **error** sur `apps/desktop/src/renderer/**` (seul code React ;
  pas sur les e2e, où l'argument `use` des fixtures Playwright serait pris pour un hook). Les règles
  « React Compiler » de react-hooks 7 ne sont pas activées.
- `linterOptions.reportUnusedDisableDirectives: 'error'` : un `eslint-disable` qui ne masque rien
  fait échouer le lint (évite de nouveaux commentaires morts).
- Ignorés : `node_modules`, `dist`, `out`, `build`, `.turbo`, `coverage`, rapports Playwright,
  `.claire/`, `.claude/`, `**/routeTree.gen.ts`, `**/*.generated.js`, `**/*.min.js`,
  `renderer/public/vendor`, données locales (`apps/desktop/PL`, `.web-data`, `.tanstack`, `data/`).
- Fichiers CommonJS (`**/*.cjs`, `deploy/**/*.js` — agent hôte GH63) : `sourceType: commonjs`,
  `no-require-imports` désactivée.

## Comment vérifier

1. `pnpm lint` à la racine → 0 problème, code de sortie 0.
2. Introduire une erreur, ex. un `useState` appelé dans un `if` d'un composant de
   `apps/desktop/src/renderer/`, ou une variable inutilisée dans `packages/types/src/` →
   `pnpm lint` échoue (`react-hooks/rules-of-hooks`, `@typescript-eslint/no-unused-vars`).
   Vérifié pendant le correctif, puis retiré.
3. `pnpm typecheck` et `pnpm test` verts.
