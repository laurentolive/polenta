# GH43 — Auto-sync : une erreur réseau (hors ligne) remontée comme erreur IPC

## Root cause

`SyncService.autoSync` (tick d'auto-pull T155/GH39, toutes les 5 min) laissait remonter toute
erreur du `git.fetch`, y compris quand le serveur est simplement injoignable (`ENOTFOUND`, DNS,
poste hors ligne). Le handler IPC `sync:auto-sync` renvoyait donc une erreur, et Electron
écrit `Error occurred in handler for 'sync:auto-sync'` dans la console du main process à chaque
tick. Le renderer (`useAutoPull`) l'interceptait bien, mais gardait le message brut
(`getaddrinfo ENOTFOUND github.com`) comme dernière erreur de sync.

## Correctif

- `net-proxy.ts` : nouveau `isNetworkUnreachable(err)`, qui reconnaît les codes réseau Node/undici
  (`ENOTFOUND`, `EAI_AGAIN`, `ECONNREFUSED`, `ECONNRESET`, `ETIMEDOUT`, `ENETUNREACH`,
  `EHOSTUNREACH`, `UND_ERR_*`) sur l'erreur ou sur sa `cause`, ainsi que le stderr de `git fetch`
  en CLI (remotes SSH : « Could not resolve host »…).
- `sync.service.ts` `autoSync` : si le fetch, ou le push de rattrapage, échoue sur une erreur
  réseau, la fonction renvoie l'état d'intégration tel qu'au dernier fetch avec `offline: true`,
  au lieu de lever une erreur. Les autres erreurs (auth, push refusé) remontent comme avant.
- `IntegrationRemoteState` (service + `@polenta/api-client`) : champ optionnel `offline?: true`.
- `useAutoPull` : si la réponse porte `offline`, la dernière erreur du repo devient le message
  traduit `layout.syncIndicator.offline` (rien n'est loggé). Comme avant, ce message ne s'affiche
  que si le repo est en alerte (`ahead`/`diverged`).

Hors scope : « Publier » et « Resynchroniser » affichent toujours l'erreur réseau brute. Ce sont
des actions lancées par l'utilisateur, l'échec doit y rester visible.

## Comment vérifier

1. Ouvrir un projet avec remote GitHub, puis couper le réseau (Wi-Fi off).
2. Attendre un tick d'auto-pull (5 min) : plus de `Error occurred in handler for 'sync:auto-sync'`
   dans la console du main process.
3. Avec une modification publiée localement mais pas poussée (état `ahead`), l'indicateur de sync
   affiche « Dernière erreur : serveur injoignable (hors ligne ?), nouvel essai automatique… ».
4. Rétablir le réseau : au tick suivant, le fetch et le push repartent et l'alerte disparaît.
