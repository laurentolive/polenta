# GH437 — `pnpm lint` échoue sur `main`

## Root cause

Quatre erreurs ESLint, toutes préexistantes, dans des fichiers que le ticket ne touche pas :

1. `apps/desktop/src/main/services/merge-resolution.service.ts` — `import * as fs` jamais utilisé
   (le module n'utilise que `fsP` = `fs/promises`).
2. `apps/desktop/src/main/git/node-checkout.gh337.test.ts` — `beforeEach` importé, jamais utilisé.
3. `apps/desktop/src/main/git/askpass/askpass.js` — script CommonJS livré tel quel (`require`) :
   `@typescript-eslint/no-require-imports`. La règle CommonJS du `eslint.config.mjs` ne couvrait que
   `**/*.cjs` et `deploy/**/*.js`.
4. Même fichier, `const prompt` : masque le global navigateur `prompt` (la config partagée charge
   `globals.browser`), `no-redeclare`. Découvert en relançant le lint après le point 3.

## Correctif appliqué

- Retrait des deux imports inutilisés (1, 2).
- `eslint.config.mjs` : `apps/desktop/src/main/git/askpass/*.js` rejoint le bloc CommonJS existant
  (`sourceType: 'commonjs'`, `no-require-imports` désactivé). Le fichier reste livré tel quel.
- `askpass.js` : variable locale renommée `promptText`. La clé du message envoyé au serveur reste
  `prompt` : le protocole ne change pas.

## Comment vérifier

- `pnpm lint` à la racine : exit 0, zéro erreur ni avertissement (`--max-warnings=0`).
- `pnpm typecheck` (desktop `tsc --noEmit`) : exit 0.
- Tests touchés : `src/main/git/askpass*`, `src/main/services/merge-resolution*`,
  `src/main/git/node-checkout.gh337` : 8 fichiers, 24 tests verts.
