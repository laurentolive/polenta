# GH47 — Vue campagne : le bouton Exporter apparaît 2 fois

## Root cause
`routes/campaign.$campaignId.tsx` monte deux `ExportButton` dans l'en-tête : le cahier de
campagne (`campaign-plan`) et, dès qu'un run n'est plus `pending`, le rapport de campagne
(`campaign-report`) — choix voulu par T43. Mais `ExportButton` affichait toujours le libellé
fixe `exportButton.export` (« Exporter ») : deux boutons identiques, impossibles à distinguer.

## Correctif
- `ExportButton` : prop optionnelle `label` (défaut inchangé : « Exporter »), utilisée pour le
  texte et le `title`.
- Vue campagne : « Exporter le cahier » / « Exporter le rapport » (`exportButton.exportPlan`,
  `exportButton.exportReport`, fr + en). Les autres vues ne changent pas.

## Vérifier
Ouvrir une campagne sans test exécuté → un seul bouton « Exporter le cahier ». Exécuter un
test → apparaît « Exporter le rapport » à côté ; chaque bouton propose ses formats
(cahier : Excel/Word/PDF, rapport : Word/PDF).
