# T132 — bug : titre de la popup d'édition de composant figé sur "Renommer {{name}}"

## Reproduction

1. Vue Système → onglet Structure.
2. Cliquer sur l'icône crayon d'un composant local, ou du repo racine (root/Produit).
3. **Constaté :** la popup s'ouvre avec le titre `"Renommer Polenta"` (ou `"Renommer <nom du composant>"`)
   alors que la popup permet bien plus qu'un renommage : label, description, rôles exposés (`RolesExposedFields`)
   et interfaces implémentées (`ImplementedInterfacesFields`) — cf. le commentaire au-dessus de
   `NodeEditModal` (`StructureTab.tsx`).

## Root cause

`NodeEditModal` (`apps/desktop/src/renderer/components/schema/StructureTab.tsx:600`) utilisait la clé
`schema.structureTab.renameTitle` (`"Renommer {{name}}"`), interpolée avec `target.repoLabel` — le nom
du repo (`node.name`), pas le nom du composant édité. Pour la racine du workspace ("Polenta"), le titre
affichait donc "Renommer Polenta" quel que soit le composant réellement en cours d'édition. Le nommage
de la clé et son contenu dataient d'avant l'ajout des sections rôles/interfaces (T123) et n'ont jamais
été mis à jour pour refléter que cette popup est une édition générale du composant, pas un simple
renommage.

## Correctif appliqué

- `apps/desktop/src/renderer/i18n/locales/fr.json` / `en.json` — remplacement de la clé
  `schema.structureTab.renameTitle` (paramétrée par `{{name}}`) par `editNodeTitle`, texte statique :
  `"Éditer le composant"` / `"Edit component"`.
- `apps/desktop/src/renderer/components/schema/StructureTab.tsx` — `NodeEditModal` utilise désormais
  `t('schema.structureTab.editNodeTitle')` sans interpolation.

Correctif ciblé sur le titre de la popup — pas de changement de comportement, pas de renommage des
clés voisines (`renameRepo`, `renameComponent`, qui restent des libellés de menu contextuel distincts
et corrects tels quels).

## Comment vérifier

1. Lancer l'app, ouvrir un projet.
2. Onglet Structure → cliquer sur l'icône d'édition du repo racine, puis d'un composant local.
3. **Attendu :** dans les deux cas, la popup affiche le titre "Éditer le composant" (au lieu de
   "Renommer Polenta" / "Renommer <nom>").
