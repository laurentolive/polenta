# T55 — Bug : drag & drop fait disparaître des items dans l'arbre

## Symptôme

Dans le panel latéral (`ElementTree`), faire glisser un dossier :
- **sur lui-même** (`position='inside'`, cible = source)
- **dans un de ses sous-dossiers** (`position='inside'`, cible = descendant de la source)

…faisait disparaître le dossier déplacé et tout son contenu.

---

## Root cause

La fonction `handleDrop` dans `ElementTree.tsx` contient un seul garde-fou :

```ts
// No-op: drop on self
if (afterId !== null && ids.includes(afterId)) { return }
```

Ce garde ne couvre que le cas `position='before'`/`'after'` où `afterId` est le nœud lui-même.
Il ne couvre **pas** le cas `position='inside'` où `parentId === dragged id` ou `parentId` est un descendant du nœud glissé.

Séquence de destruction :
1. `treeRemoveMany(root, ids)` — supprime le nœud source (et toute sa descendance).
2. `treeInsert(pruned, n, parentId, ...)` — tente d'insérer dans `parentId` qui n'existe plus
   → l'insertion silencieusement ne fait rien.
3. `onRootChange(pruned)` — le nœud a disparu sans jamais être réinséré.

---

## Correctif

### 1. Nouvelle fonction `treeIsAncestorOrSelf` dans `useTreeState.ts`

```ts
export function treeIsAncestorOrSelf(
  root: TypeTreeNode[],
  ancestorId: string,
  nodeId: string,
): boolean
```

Retourne `true` si `ancestorId === nodeId` **ou** si `ancestorId` est ancêtre de `nodeId` dans l'arbre.

### 2. Garde supplémentaire dans `handleDrop` (ElementTree.tsx)

```ts
// Prevent dropping a node into itself or any of its descendants
if (parentId !== null && ids.some(id => treeIsAncestorOrSelf(root, id, parentId))) {
  setDraggingIds([])
  setDropIndicator(null)
  return
}
```

Ce garde couvre les deux cas :
- **Drag sur soi-même** : `treeIsAncestorOrSelf(root, folderId, folderId)` → `true` (égalité).
- **Drag dans un sous-dossier** : `treeIsAncestorOrSelf(root, folderId, subFolderId)` → `true` (ancêtre).

## Reproduction manuelle

1. Lancer l'app Electron en mode dev.
2. Créer un dossier **A** contenant un dossier **B**.
3. **Bug 1** : Glisser le dossier **A** et le déposer *sur lui-même* (zone centrale bleue).
   - Avant fix : A disparaît.
   - Après fix : aucun changement (no-op).
4. **Bug 2** : Glisser le dossier **A** et le déposer *à l'intérieur* du dossier **B** (qui est enfant de A).
   - Avant fix : A et B disparaissent.
   - Après fix : aucun changement (no-op).
5. Vérifier que le drag & drop normal (vers un autre dossier ou une autre position) fonctionne toujours.
