# T57 — Menu contextuel (clic droit) dans l'arbre de versions

**Statut** : specifying  
**Branche** : T57  
**Worktree** : `../polenta-T57/`

---

## Description fonctionnelle

Ajouter un menu contextuel (clic droit) sur la page `/graph` (Arbre de versions). Le menu est **contextuel selon l'élément cliqué** :

- **Badge de branche** → actions sur cette branche
- **Badge de tag** → actions sur ce tag
- **Reste de la ligne** (SHA, message, auteur, date) → actions sur ce commit (SHA)

L'action s'applique directement à l'objet sélectionné, sans ambiguïté.

## Comportements détaillés

### Checkout branche / tag / commit
- **Branche** : `checkoutBranch(repoPath, name)` — déjà implémenté
- **Tag / commit** : `checkoutCommit(repoPath, sha)` — déjà implémenté
- Post-action : invalider `sync:status`, `sync:graph`, `action:current`

### Merger branche → courant
- `merge(repoPath, branchName)` — méthode SyncService existante, **IPC handler `sync:merge` manquant**
- En cas de conflit : toast d'erreur listant les fichiers en conflit
- Post-action : invalider `sync:status`, `sync:graph`

### Rebaser courant sur branche / commit
- **Nouveau** : `rebase(repoPath, onto: string)` — rebase la branche courante sur le SHA ou nom de branche fourni
- Implémentation : `git.rebase({ onto })` via isomorphic-git (ou séquence manuelle si API insuffisante)
- En cas d'échec (conflits, erreur) : toast d'erreur explicite
- Post-action : invalider `sync:status`, `sync:graph`

### Pousser branche
- **Nouveau** : `pushBranch(repoPath, branchName, remote='origin')` — push une branche spécifique (le `push` actuel pousse la branche courante sans paramètre de branche)
- Post-action : invalider `sync:status`

### Supprimer branche locale
- `deleteBranch(repoPath, name)` — déjà implémenté
- Confirmation visuelle : item rouge, second clic confirme (même pattern que VersionPanel)
- Post-action : invalider `sync:graph`

### Supprimer branche remote
- **Nouveau** : `deleteRemoteBranch(repoPath, name, remote='origin')`
- Appelle `git.push({ remote, delete: true, remoteRef: name })`
- Post-action : invalider `sync:graph`

### Supprimer tag local
- **Nouveau** : `deleteTag(repoPath, tagName)`
- Appelle `git.deleteRef({ ref: 'refs/tags/<tagName>' })`
- Post-action : invalider `sync:graph`

### Créer une branche depuis SHA / tag
- Prompt inline (input dans le menu) pour saisir le nom
- **Nouveau** : `createBranchAt(repoPath, name, sha)` — `git.branch({ ref: name, object: sha, checkout: false })`
- Post-action : invalider `sync:graph`

### Créer un tag sur SHA
- Prompt inline pour saisir le nom
- `createTag(repoPath, tagName, sha)` — déjà implémenté (IPC `sync:create-tag` existant avec SHA optionnel)
- Post-action : invalider `sync:graph`

### Diff vs HEAD / Diff vs branche…
- Panneau inline sous la ligne concernée (extension du `CommitFilesRow` existant)
- **Nouveau** : `diffBetween(repoPath, sha1, sha2)` → `SyncFileStatus[]` — liste les fichiers différents entre deux commits quelconques
- "Diff vs HEAD" : sha1 = SHA ciblé, sha2 = HEAD sha courant
- "Diff vs branche…" : mini-sélecteur de branche inline → résout sha2 = tête de branche → appelle `diffBetween`
- Chaque fichier du panneau est cliquable → navigue vers `/diff?projectId=…&filepath=…&commitSha=sha1`

## Interactions UX

- Le menu se ferme au clic ailleurs ou appui Echap
- Les items destructifs (Supprimer, Supprimer remote) sont affichés en rouge
- La items destructifs demandent une confirmation par double-clic (item → "Confirmer ?" → clic)
- Les prompts de nom (créer branche, créer tag) apparaissent directement dans le menu (input + Enter/Echap)
- Les mutations en cours affichent un spinner sur l'item concerné

## Critères d'acceptation

- [ ] Clic droit sur un badge de branche courante : pas de "Checkout", pas de "Supprimer locale", "Merger" absent
- [ ] Clic droit sur badge de branche non-courante, repo propre : tous les items visibles
- [ ] Clic droit sur badge de branche, repo sale : "Checkout" et "Rebaser" absents
- [ ] Clic droit sur badge de tag : menu tag affiché (pas menu branche ni commit)
- [ ] Clic droit sur reste de ligne (SHA/message) : menu commit affiché
- [ ] Checkout branche → branche courante change dans le header
- [ ] Créer branche depuis SHA → branche visible dans graph sur ce SHA
- [ ] Créer tag → tag visible dans graph sur ce SHA
- [ ] Merger branche X → courant : nouveau commit de merge dans graph
- [ ] Merger branche X → courant avec conflit : toast d'erreur avec liste fichiers
- [ ] Rebaser courant sur SHA → historique linéarisé dans graph
- [ ] Pousser branche → ahead count remis à 0 dans status
- [ ] Supprimer branche locale : demande confirmation, puis disparaît du graph
- [ ] Supprimer branche remote : branche remote disparaît (vérifiable via `git fetch`)
- [ ] Supprimer tag : tag disparu du graph
- [ ] Diff vs HEAD : panneau inline avec liste de fichiers modifiés
- [ ] Diff vs branche : sélecteur de branche → panneau avec fichiers
- [ ] Clic fichier dans panneau diff → navigation vers vue diff
- [ ] Clic ailleurs ou Echap → menu se ferme
