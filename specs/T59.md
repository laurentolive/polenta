## Description fonctionnelle

Créer une nouvelle page dédiée au diff entre deux objets git (branche, tag, commit), accessible depuis un bouton icône dans le panel latéral de version — à côté des icônes Baselines (Tag) et Arbre de versions (History).

Cette page remplace l'affichage inline du diff actuellement dans la page `/graph` (CommitFilesRow avec diffShas).

## Panel latéral — détail

### Combobox Objet A et Objet B

Chaque combobox affiche la liste de tous les objets git disponibles, regroupés :
- **Branches locales** — nom seul (ex: `main`, `feature/foo`)
- **Branches remote** — préfixées `origin/` (ex: `origin/main`)
- **Tags** — préfixés d'un label (ex: `v1.0.0`)
- **Commits récents** — SHA court + début du message (ex: `abc1234 fix: …`)

La valeur affichée dans la combobox précise le type :
- Branche : `⎇ main`  
- Tag : `⊙ v1.0.0`
- Commit : `# abc1234`

Les comboboxes sont **pré-remplies** quand on navigue depuis la page graph (paramètres d'URL `ref1` et `ref2`).

### Liste de fichiers

- Affichée sous les deux comboboxes
- Calculée via `api.sync.diffBetween(repoPath, sha1, sha2)` (déjà implémenté en T57)
- Chaque fichier : marqueur M/A/D coloré + chemin
- Clic sur un fichier → l'affiche dans la zone principale
- Le fichier sélectionné est surligné

---

## Zone principale

- Affiche le diff d'un fichier entre les deux objets choisis
- Utilise `api.sync.commitDiff(repoPath, sha, filepath)` en adaptant pour deux SHAs arbitraires, ou crée `diffFileBetween(repoPath, sha1, sha2, filepath)` → `{ oldContent, newContent }`
- Rendu identique à la vue `/diff` existante (même composant ou même logique)
- Si aucun fichier sélectionné : message "Sélectionnez un fichier dans le panel latéral"

---

## Route

Nouvelle route `/version-diff` avec paramètres de recherche :
```typescript
{
  projectId: string
  ref1?: string   // nom de branche ou tag (résolu en sha1 côté renderer)
  sha1?: string   // SHA direct
  ref2?: string
  sha2?: string
}
```

Priorité : `sha` > `ref` (si sha fourni, on l'utilise directement ; sinon on résout `ref` via la liste de commits/branches).

## Intégration dans VersionPanel

Ajouter un troisième bouton icône entre Tag (baseline) et History (graph), ou après History :

```tsx
<button onClick={() => navigate({ to: '/version-diff', search: { projectId } })}
  title="Comparer deux versions">
  <GitDiff size={14} />   {/* icône lucide-react */}
</button>
```

## Nouveau service nécessaire

`diffFileBetween(repoPath, sha1, sha2, filepath)` → `{ oldContent: string; newContent: string }`

Similaire à `commitDiff` mais compare deux SHAs arbitraires (pas commit vs parent) :
- `oldContent` = contenu du fichier au SHA sha1
- `newContent` = contenu du fichier au SHA sha2

IPC : `sync:diff-file-between`
