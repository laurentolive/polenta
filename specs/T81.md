# T81 — Renommage nomenclature de branches `prj-*`/`tck-*` → `int-*`/`dev-*`

## Contexte

T30 a introduit deux familles de branches git pour la gestion de configuration d'un projet Polenta :
- `prj-*` : branches "projet", en lecture seule dans l'UI, modifiées uniquement par merge
- `tck-*` : branches "ticket", éditables

Ce nommage entre en collision conceptuelle avec la notion de **ticket** du workflow de développement de Polenta lui-même (`TICKETS.md`/`WORKFLOW.md`, tickets `T{N}`). Un utilisateur ou un agent lisant "branche tck-" peut la confondre avec un ticket Polenta. Renommage :
- `prj-*` → `int-*` (intégration)
- `tck-*` → `dev-*` (développement)

Décision actée le 2026-07-10 (cf. mémoire `project_t30_versioning` / `project_version_view_multirepo`).

## Description fonctionnelle

Renommage mécanique du préfixe de nomenclature, sans changement de comportement fonctionnel :
- Toute branche actuellement préfixée `prj-` doit désormais être créée/reconnue avec le préfixe `int-`
- Toute branche actuellement préfixée `tck-` doit désormais être créée/reconnue avec le préfixe `dev-`
- La logique de lecture seule (readonly) associée aux branches d'intégration reste inchangée, seul le préfixe testé change
- Les identifiants de code (fonctions, variables, types) reflétant l'ancienne nomenclature sont renommés en cohérence (`prj` → `int`)
