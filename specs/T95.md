# T95 — Correction d'emplacement : autoPropagatePin dans le panneau latéral

## Root cause

T94 avait placé la préférence `autoPropagatePin` dans un nouvel onglet **Préférences** de la page
Modèle de données (`/schema`). Retour utilisateur : l'option doit se trouver dans le **panneau
latéral Projet**, sous le lien « Modèle de données », pas dans la page elle-même.

## Correctif appliqué

- `apps/desktop/src/renderer/routes/schema.tsx` : suppression de l'onglet Préférences
  (`PreferencesTab`, entrée `TABS`, rendu, champ `autoPropagatePin` de `EditorState`). Le champ
  `schema.preferences` est désormais passé tel quel par `editableToSchema` (nouveau paramètre
  `preferences`, même principe que `nodes` déjà passé en paramètre car possédé ailleurs) —
  un save depuis cette page ne l'écrase plus.
- `apps/desktop/src/renderer/components/sidebar/ProjectPanel.tsx` : ajout de la case à cocher
  sous le lien « Modèle de données » dans `WithProjectPanel`, lecture via `useProjectSchema`,
  sauvegarde immédiate (`api.schema.save` avec le schéma complet + `preferences` patché) au
  changement — pas de brouillon, cohérent avec un réglage de panneau latéral plutôt qu'un champ
  d'éditeur.

Pas de changement côté `packages/types/src/schema.ts` ni `schema.service.ts` (déjà corrects
depuis T94).

## Comment vérifier

1. Ouvrir un projet — panneau latéral **Projet**, sous le lien « Modèle de données », la case
   « Propager automatiquement le pin des sous-repos » doit apparaître (décochée par défaut).
2. La cocher → écrit immédiatement dans `.polenta/schema.yaml` (`preferences.autoPropagatePin: true`),
   sans passer par la page /schema.
3. Aller sur /schema, onglet Liens ou Interfaces, modifier puis Enregistrer → vérifier que
   `preferences.autoPropagatePin` reste inchangé dans le fichier (non écrasé).
4. Page /schema : l'onglet Préférences n'existe plus (Structure / Liens / Interfaces seulement).

`npm run typecheck` (turbo, filtre desktop+types) — 0 erreur.

**Non testé interactivement** (pas d'Electron attachable dans cette session) — attend validation
manuelle humaine avant archivage/merge.
